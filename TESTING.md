# Go Through Tabs — проверка версии 1.1.0

Проверки выполнены 5 октября 2026 года.

- `npm test`: 13 сценариев модели истории, все прошли.
- `npm run test:popup`: 7 групп сценариев в установленном Google Chrome 154.0.8037.93, с отдельным временным профилем.
- Настоящее окно из панели Chrome открывалось через `chrome.action.openPopup()`: проверены включение и отключение клавишами Space/Enter, состояние фонового модуля, повторное открытие и обе темы. Для доступа к этому отдельному контексту Chrome используется CDP.
- Проверены Tab, видимый фокус, клавиатурное раскрытие помощи, ширина 340 px и узкий viewport 280 px, перенос русского текста, контраст текста и переключателя, reduced motion и forced colors.
- В том же документе popup с подменённым транспортом проверены загрузка, задержка переключения, быстрые повторные нажатия, ошибки связи, некорректный ответ, тайм-аут и позднее завершение. Повторная проверка читает состояние и не повторяет `toggle`.
- Проверены обычное и длинное уведомления, безопасное отображение текста, доступная с клавиатуры прокрутка и очистка уведомления при переключении.
- Сохранены и просмотрены скриншоты в `screenshots/`; `popup-native-light.png` и `popup-native-dark.png` сняты с настоящего окна Chrome. `popup-test-results.json` содержит результаты сценариев. Ошибок JavaScript и внешних запросов страниц теста нет.
- Статический аудит frontend-design-premium в строгом режиме: 0 замечаний; отчёт `premium-audit.json`. Официальный валидатор DESIGN.md: 0 ошибок (информационные предупреждения о ссылках на токены в документации; runtime использует канонические CSS-переменные).
- `history.js`, `background.js` и `content.js` побайтно совпадают с поставкой 1.0.0. Логика истории и ключи хранения не изменены.
- ZIP версии 1.1.0 проверен через `unzip -t`; рядом сохранена и проверена SHA-256.

Расширение проверялось в отдельном профиле. В основном профиле для обновления нужно нажать **Обновить** на карточке расширения в `chrome://extensions/` и перезагрузить веб-вкладки. Подробности — в README.

## Проверки предыдущей версии 1.0.0

Проверки выполнены 5 октября 2026 года.

- Тесты модели: 13 сценариев, все прошли.
- Загруженное расширение проверено в установленном Google Chrome 154.0.8037.93, с отдельным временным профилем и реальными API Chrome.
- Проверены полный цикл A0 → A1 → A2 → B0 → B1, разные домены, вложенная цепочка A → B → C, сохранение внутренней истории и порядок вкладок.
- Проверены SPA (`pushState`, `replaceState`), фрагменты, одинаковые адреса, история и клавиатура фреймов, новая ветка, посторонние закрытые вкладки и быстрые повторные команды.
- Проверены остановка и пробуждение service worker, а также восстановление по URL при недоступной сессии.
- Проверены ссылка в фоне, перестановка исходной вкладки, её перезагрузка и ручное закрытие источника. В заключительном прогоне отключение back-forward cache из стандартных аргументов Playwright снято: используется штатное решение Chrome о кешировании страниц.
- ZIP проверен через `unzip -t`; рядом с архивом сохранена SHA-256.

Браузерные тесты отправляют доверенные клавиатурные события через Playwright. Дополнительная проверка клавиш через интерфейс macOS **не завершена**: инструмент Computer Use вернул `noWindowsAvailable`, тестовый сценарий ожидания клавиш завершился по тайм-ауту. Это не результат проверки работы расширения с аппаратной клавиатурой. Для повторения вручную предназначен `tests/native.mjs` и сценарий в README.

Основной профиль пользователя и установленное Close on Back не изменялись. Расширение не установлено в основной профиль: готова папка для «Загрузить распакованное расширение».
